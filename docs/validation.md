# 驗證紀錄

## 已編譯

AI-Thinker ESP32-CAM，Arduino-ESP32 3.3.12，min_spiffs（雙 OTA）、40 MHz。編譯輸出見 [esp32_clock-build.txt](esp32_clock-build.txt)。

## 主機測試

`python tools/build.py test`，輸出見 [host-tests.txt](host-tests.txt)。測試跑真正的控制程式，外設為模擬，模擬計時器以微秒精度觸發。

- 馬達：參數上限、半步相序、跨移動與重開機延續相位、加減速曲線、停止／故障／逾時都關線圈、millis 溢位。
- 走時：多頁連續移動、暫停、停止、故障清除、斷電還原、等待網路時間、領先時原地等待。
- 網頁：登入、鎖定、憑證、改密碼、Wi-Fi 掃描與試連、OTA 失敗與成功。
- 偏移：只正轉、位置保留、永久儲存、重新歸零不清除。
- 保存：截斷、逐位元破壞、A/B 選擇、寫入失敗。
- 網頁也用模擬後端在瀏覽器跑過登入、歸零、偏移、驗證、儲存、改密碼（這是 0.3.0 的頁面，0.4.0 只移除 Uno 連線欄位）。

模擬不包含 RF、實際計時抖動、電氣雜訊、機械阻力、電壓下陷，所以不能取代實機。

## 已知限制

- 沒有原點感測器，步數送完不代表機構確實翻頁。
- 少了雙主控時 Uno 的獨立保護：ESP 當機時，移動已有步數上限，但線圈要等 ESP 重開機才一定會關。
- 連線是一般 HTTP，密碼在區網上沒有加密。
- NTP 是未認證的時間來源；差超過 5 分鐘要在網頁確認。
